## BUG CRITIQUE — Controllers ne renvoient pas les données

**15 endpoints → `{"success": true, "data": null}`**

Pattern buggy (4 controllers):
```go
results, err := service.GetAll(ctx)
res.SetSuccess("")
_ = results  // ← DATA JETÉE
```

Pattern correct (ex: abnormal_recipient):
```go
res.Data.Total = total
res.Data.List = apiList
res.SetSuccess(msg)
```

### GoFrame Response Pattern
```go
type StandardRes struct {
    Success bool        `json:"success"`
    Code    int         `json:"code"`
    Msg     string      `json:"msg"`
    Data    interface{} `json:"data"`  // ← CE CHAMP EST VIDE
}
```
